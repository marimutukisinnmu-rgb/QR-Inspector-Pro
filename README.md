# QR Inspector Pro

ブラウザでQRコードを読み取り、結果とデコードされたバイト列を確認するツールです。

## 機能

- QR画像のドラッグ＆ドロップ、ファイル選択、クリップボード画像貼り付け
- カメラでのQRコード読み取り
- QRデコード結果とデータサイズの表示
- デコード結果の16進数・ASCIIダンプ
- HEXバイト列の手動入力
- テキスト入力とUTF-8バイト列表示
- バイト列を .bin ファイルとして保存

## 使い方

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages から main ブランチの /(root) を公開対象に設定してください。

またはローカルで `index.html` をブラウザで開きます。カメラを使う場合は HTTPS または localhost が必要です。

## 注意

QR認識には jsQR をCDNから読み込みます。初回読み込み時はインターネット接続が必要です。

この実装はQRデコーダーが返すバイト列を表示します。全ての特殊なQRセグメントを規格レベルで完全復元することを保証するものではありません。バイナリ入力欄は16進数のバイト列を解析するためのもので、任意形式のバイナリファイルをQR画像として解釈する機能とは異なります。
